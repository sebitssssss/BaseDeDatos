¿Qué es SQL?

SQL es un lenguaje que sirve para hablar con las bases de datos. Con él le podemos pedir a la base de datos que nos muestre datos, que guarde datos nuevos, que cambie algo que ya estaba o que borre lo que no hace falta.

Algunas bases de datos que entienden SQL son MySQL, PostgreSQL, SQL Server y SQLite.

Funciones básicas de SQL

Estas son las cosas que más se usan cuando uno empieza con SQL:

1. SELECT - Ver datos

Se usa para pedirle a la base de datos que nos muestre información de una tabla.

-- Mostrar todo lo que hay en la tabla usuarios
SELECT * FROM usuarios;

-- Mostrar solo el nombre y el email
SELECT nombre, email FROM usuarios;

2. INSERT - Agregar datos

Sirve para meter un dato nuevo dentro de una tabla.

INSERT INTO usuarios (nombre, email)
VALUES ('Juan', 'juan@email.com');

3. UPDATE - Cambiar datos

Sirve para modificar un dato que ya existe. Hay que tener cuidado de decirle bien a quién cambiarle el dato, porque si no le cambia a todos.

UPDATE usuarios
SET nombre = 'Juan Pérez'
WHERE id = 1;

4. DELETE - Borrar datos

Sirve para borrar una fila. Igual que con UPDATE, hay que usar WHERE para borrar solo lo que queremos.

DELETE FROM usuarios
WHERE id = 1;

5. WHERE - Filtrar

Se pone junto con SELECT, UPDATE o DELETE para que solo tome en cuenta las filas que cumplen una condición.

SELECT * FROM usuarios
WHERE edad >= 18;

6. ORDER BY - Ordenar

Sirve para que los resultados salgan ordenados, por ejemplo alfabéticamente.

SELECT * FROM usuarios
ORDER BY nombre ASC;

7. JOIN - Unir tablas

Sirve cuando tenemos los datos repartidos en dos tablas y queremos verlos juntos en un solo resultado.

SELECT usuarios.nombre, pedidos.producto
FROM usuarios
JOIN pedidos ON usuarios.id = pedidos.usuario_id;

Stored Procedures (Procedimientos Almacenados)

Un Stored Procedure es un conjunto de instrucciones SQL que se guarda adentro de la base de datos. En vez de escribir lo mismo muchas veces, lo escribimos una sola vez, lo guardamos, y después solo lo llamamos cuando lo necesitamos.

¿Para qué sirven?

  • Para no repetir el mismo código SQL una y otra vez.
  • Para que la aplicación ande más rápido, porque la base de datos ya tiene el código listo.
  • Para tener más seguridad, porque el usuario no ve toda la consulta.
  • Para hacer operaciones más complejas de una sola vez.

Ejemplo: Crear un Stored Procedure

Este ejemplo es para MySQL. Guarda un procedimiento que busca usuarios que tengan cierta edad o más:

DELIMITER //

CREATE PROCEDURE buscar_por_edad(IN edad_minima INT)
BEGIN
    SELECT * FROM usuarios
    WHERE edad >= edad_minima
    ORDER BY nombre;
END //

DELIMITER ;

Ejemplo: Llamar al Stored Procedure

Para usar el procedimiento que guardamos, escribimos CALL y el nombre:

-- Buscar usuarios de 18 años o más
CALL buscar_por_edad(18);

Ejemplo con parámetros de salida (OUT)

Los parámetros OUT sirven para que el procedimiento nos devuelva un valor. En este caso, contamos cuántos usuarios hay en total:

DELIMITER //

CREATE PROCEDURE contar_usuarios(OUT total INT)
BEGIN
    SELECT COUNT(*) INTO total FROM usuarios;
END //

DELIMITER ;

-- Lo llamamos y guardamos el resultado
CALL contar_usuarios(@cantidad);
SELECT @cantidad AS total_de_usuarios;
